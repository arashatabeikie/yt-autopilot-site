Privacy Policy

Last updated: 28 October 2026

YT Autopilot is a private, self-hosted tool. It is used only by its owner to manage the owner's own YouTube channels. It does not offer accounts to anyone else.

Data we access

With the owner's permission (Google sign-in), YT Autopilot uses the YouTube API Services to access:

  • Channel information: channel name, ID, and public statistics (subscribers, views, video count).
  • YouTube Analytics reports for the owner's channels (for example views and watch time).
  • The ability to upload, schedule, and edit videos on the owner's channels.

How the data is used

The data is used only to show the owner how their channels perform and to publish videos the owner has approved. It is not sold, shared with third parties, or used for advertising.

Where the data is stored

Everything is stored on the owner's own computer. Google sign-in tokens are encrypted. No data is sent to any server run by YT Autopilot, because there is none.

How long data is kept, and how to delete it

Channel statistics are kept on the owner's computer until the owner deletes them. Access can be revoked at any time at Google Account → Third-party connections, which immediately stops YT Autopilot from accessing YouTube.

Google and YouTube

YT Autopilot uses YouTube API Services. By using it, you are also bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.
